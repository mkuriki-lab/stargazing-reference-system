## 概要

従来のシステムでは、固定された星座早見画像が表示されるため、実際の観測映像との不整合が生じる問題があった。
観測地点（緯度・経度）およびアクセス日時に同期して星座早見画像を動的に生成するシステムの開発を行った。

ただ、結果的に手入力で緯度経度と日時を指定して、生成するシステムの開発に取り組んだ。
---

## 実行環境

本システムは以下の環境での動作を想定している。

- Linux（Ubuntu等）
- Stellarium
- ImageMagick
- Apache
- PHP
- Bash

---

## システム構成

本システムは以下の3つの要素で構成される。

### 1. Web UI（`03_web_ui/`）

ユーザーがブラウザから星空生成条件を入力するインターフェース。

- **入力**
  - 緯度（Latitude）
  - 経度（Longitude）
  - 日時（Date & Time）

- **動作**
  - PHP（`control.php`）で入力値を受け取り、テキストファイル（`request.txt`）に書き込む

- **結果**
  - バックエンド処理をトリガーする

---

### 2. 星空画像生成処理（`02_stellarium_generator/`）

Stellariumと画像処理を用いたコア処理。

- **入力**
  - `request.txt` に記録された座標・日時

- **動作**
  1. `watcher.sh` がファイル更新を監視
  2. `template.ssc` を書き換え、Stellarium用スクリプトを生成
  3. Stellariumを起動し全天スクリーンショットを取得
  4. ImageMagickで円形に切り抜き（透過処理）

- **結果**
  - 円形の星空画像（.png）を出力

---

### 3. 初期プロトタイプ（`01_prototype/`）

drawstarsを用いた星空描画の検証プログラム（最終システムでは未使用）。

- **入力（引数）**
  - `--lat` 緯度
  - `--lon` 経度
  - `--date` 日時
  - `--out` 出力ファイル名

- **動作**
  - 星表データ（Hipparcosカタログ）をもとに星の位置を計算し画像生成

- **結果**
  - 星空画像（.jpg / .png）

## 開発プロセス

### 1. 初期検証フェーズ（drawstars）

- オープンソースの星空描画プログラムを使用
- Linux環境でビルド・実行
- コマンドライン引数を変更しながら星空画像生成を検証
- 星表データ（Hipparcos-2）を使用

→ 精度・拡張性の観点からStellariumへ移行

---

### 2. コアシステム開発フェーズ（Stellarium）

- Stellariumを外部スクリプトから制御
- 投影法：ステレオ投影法
- 視点：天頂（高度90度）
- 画角：180度（全天表示）

#### 表示調整
- 星のサイズ拡大
- 星座線・星座名の表示
- 大気光・地上風景の非表示

#### 画像処理
- ImageMagickで円形切り抜き
- 背景透過処理

---

### 3. 連携システム開発フェーズ

- Web UI（HTML）作成
- PHPで入力値をファイルへ書き込み
- `watcher.sh` による監視処理
- `make_circle.sh` による自動生成処理

---

### 4. 動作検証

日時：2026年1月25日 21:00 に固定

→ 入力パラメータに応じた正しい星空生成を確認
